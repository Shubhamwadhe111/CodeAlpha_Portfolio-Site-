# 🚀 Shubham Wadhe — Professional AI & Data Science Portfolio

A modern, high-performance personal portfolio website built with semantic HTML5, clean modern CSS, JavaScript, and interactive **Three.js** 3D WebGL graphics.

---

## ✨ Features & Architecture

- **Right-Side Curved Arc Navbar (Interactive Scrolling Animation)**:
  - Custom crescent arc path docked on the right side of the screen.
  - Section nodes (**Home, About, Skills, Projects, Achievements, Education, Contact**) aligned along the curve.
  - Real-time SVG path scroll tracking with animated travel line and dynamic percentage progress counter.
  - Responsive mobile drawer navigation for smaller viewports.
- **Minimalist Professional Dark Mode (No Neon)**:
  - Deep obsidian space palette (`#090a0f`) with subtle slate cards, hairline borders (`rgba(255, 255, 255, 0.08)`), and crisp typography.
  - Clean high-contrast white primary buttons and subtle sapphire blue accents.
- **3D Interactive Geometric Structure (Three.js)**:
  - Real-time metallic icosahedron sculpture with studio lighting and orbital coordinate rings.
  - Interactive click-and-drag rotation with physics damping.
  - Subtle, non-distracting ambient canvas dust particles.
- **Featured Projects**:
  - **LINGUA** – ML-Based Language Tutor (Adaptive diagnostic feedback & AI assistance)
  - **AI-Based Crop Recommendation System**
  - **College Event Management System**
  - **Patient Case Tracking System** (Smart India Hackathon project)
  - Real-time category filtering (*All, AI & Machine Learning, Web Applications*).
- **Interactive Resume Modal & PDF Print Support**:
  - Formatted digital CV accessible directly in the browser.
  - Native print stylesheet enabling instant save-as-PDF.
- **Direct Contact System**:
  - Validated contact form that generates a pre-formatted message dispatch.
  - One-click links for direct phone call, email, and LinkedIn.

## 🌐 Deploying to GitHub Pages

1. Go to your repository on GitHub: `https://github.com/Shubhamwadhe111/CodeAlpha_Portfolio-Site-`
2. Click **Settings** (top menu bar).
3. On the left sidebar under *Code and automation*, click **Pages**.
4. Under **Build and deployment** > **Branch**:
   - Choose `main` branch.
   - Choose `/ (root)` folder.
   - Click **Save**.
5. Within 1–2 minutes, your website will be live at:
   `https://shubhamwadhe111.github.io/CodeAlpha_Portfolio-Site-/`
